# Bula Fácil

> Projeto piloto desenvolvido para facilitar a consulta e a compreensão de informações sobre medicamentos, mantendo a fidelidade a fontes oficiais (como a Anvisa) com uma linguagem acessível.

---

## Sobre o Projeto

O **Bula Fácil** nasceu com o objetivo de ajudar pessoas que encontram dificuldades para entender termos técnicos complexos em bulas extensas. A ideia surgiu deposi que eu vi a dificuldade dos meus avós. O sistema fornece um resumo claro, focado em segurança, indicações, cuidados e contraindicações, sempre atrelado à fonte original do medicamento.

---

##  Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias:

* **Backend:** Python, FastAPI, Uvicorn
* **Banco de Dados:** SQLite
* **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
* **Versionamento:** Git & GitHub
